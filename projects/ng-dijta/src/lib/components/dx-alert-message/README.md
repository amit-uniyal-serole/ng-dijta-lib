## Module
>`import { DxAlertMessageModule } from '@ngdx/dijta';`

## Selector
>`<dx-alert-message></dx-alert-message>`

## Inputs

| Input  | Data need to be passed as input |
| ------------- | ------------- |
| **msg** (string) | `message to be displayed`  |
| **type** (messageType) | `success(green) | error(red)`  |
