**Module**
`DxTogglePanelModule`

## Inputs

| Input                           | Data need to be passed as input           |
| ------------------------------- | ----------------------------------------- |
| **panelToggle** (PANEL_TOGGLE)  | `toggle panel with open and close values` |
| **direction** (PANEL_DIRECTION) | `open panel from left or right`           |

**selector**

`<dx-toggle-panel [panelToggle]="togglePanel?'open':'close'" [direction]="'right'"> content </dx-toggle-panel>`
