Icon Primitive

<dx-icon> is a thin, token-aligned wrapper around Angular Material's mat-icon. It standardises icon sizing, font-set selection, and accessibility handling across the library — decorative icons are hidden from screen readers by default, and semantic icons opt-in via ariaLabel.

<dx-icon name="notifications" size="md" fontSet="outlined"></dx-icon>

Accessibility

dx-icon applies aria-hidden="true" to the host by default — correct for decorative icons. Pass ariaLabel to make an icon semantic; the label is announced by screen readers and aria-hidden is automatically removed.

Decorative (default)

The icon conveys no meaning — it is visual reinforcement only. aria-hidden="true" is set automatically; no attribute needed in the template.

<dx-icon name="close"></dx-icon>
Semantic (ariaLabel)

The icon carries meaning on its own (e.g. icon-only button). Set ariaLabel to the translated string — aria-hidden is removed automatically.

<dx-icon name="notifications" [ariaLabel]="'dx.aria.notifications' | transloco"> </dx-icon>
