# Colors

Every colour in `@ngdx/dijta` is exposed as a CSS custom property declared on
`:root` in
[`theme/partials/_default.scss`](?path=/docs/foundations-colors--docs). Components
reference these variables (e.g. `background: var(--primary-base)`) — never raw
hex — so the whole library re-skins by overriding the variables.

Swatches below are filled from the **live** variables, so they always reflect
the values currently loaded in the theme.

## Colour utility classes

The library also ships background/foreground utility classes (in
`theme/partials/_color.scss`) that pair a surface variable with its matching
`on-*` text variable. Apply them to any element:

<Unstyled>
  <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(150px, 1fr))', gap: '8px', maxWidth: '640px' }}>
    {[
      ['primary-base', '--primary-base', '--primary-on-base'],
      ['primary-light', '--primary-light', '--primary-on-light'],
      ['primary-dark', '--primary-dark', '--primary-on-dark'],
      ['secondary-base', '--secondary-base', '--secondary-on-base'],
      ['secondary-light', '--secondary-light', '--secondary-on-light'],
      ['secondary-dark', '--secondary-dark', '--secondary-on-dark'],
      ['background-base', '--background-base', '--background-on-base'],
      ['background-light', '--background-light', '--background-on-light'],
      ['background-dark', '--background-dark', '--background-on-dark'],
      ['surface-base', '--surface-base', '--surface-on-base'],
      ['surface-light', '--surface-light', '--surface-on-light'],
    ].map(([cls, bg, fg]) => (
      <div
        key={cls}
        style={{
          background: `var(${bg})`,
          color: `var(${fg})`,
          padding: '12px',
          borderRadius: '6px',
          border: '1px solid rgba(0,0,0,.1)',
          fontSize: '13px',
          fontFamily: 'monospace',
        }}
      >
        .{cls}
      </div>
    ))}
  </div>
</Unstyled>
