# Elevation

A Material-style shadow scale defined in
[`theme/common/_elevation.scss`](?path=/docs/foundations-elevation--docs). Apply
a level with the `.elevation-z-{n}` class to give a surface depth. `z-0` /
`elevation-none` removes the shadow.

Cards below use the real classes, so each shadow is exactly what the library
renders.

  </div>
