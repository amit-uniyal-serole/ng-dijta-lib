# Typography

The type system is defined in
[`theme/typography/`](?path=/docs/foundations-typography--docs). The named ramp
(`$dx-typography`) is generated by `theme-builder` into classes scoped under
`.dx-typography` — added to `<body>` globally — so any element can opt into a
ramp level by class name (e.g. `<h2 class="heading-2">`).

Font family is **Inter**, falling back to `sans-serif`.

## Type ramp

Each row renders with its real class so the sample is exactly what the library
produces.

## Font-size scale

The raw `$fontsize` map (`theme/typography/_variables.scss`) that the ramp draws
from. A 1.2 (minor-third) scale for headings, plus fixed sizes for UI text.

<Typeset
  fontSizes={[
    '12px', '13px', '14px', '16px',
    '17.07px', '18.22px', '19.44px', '20.74px', '22.13px', '23.61px',
  ]}
  fontWeight={400}
  sampleText="The quick brown fox"
  fontFamily="Inter, sans-serif"
/>

| Token | Size | Used by |
|---|---|---|
| `info` / `paragraph` | 12px | helper text, captions |
| `label` | 13px | field labels |
| `subbody` / `input` / `button` | 14px | secondary body, inputs, buttons |
| `subtitle` / `body` | 16px | body copy, subtitles |
| `h6` | 17.07px | heading 6 |
| `h5` | 18.22px | heading 5 |
| `h4` | 19.44px | heading 4 |
| `h3` | 20.74px | heading 3 |
| `h2` | 22.13px | heading 2 (default heading) |
| `h1` | 23.61px | heading 1 |

## Font weights

The `$font-weights` map, also exposed as `.fw-*` utility classes
(`theme/partials/_font-weight.scss`).

<Unstyled>
  <div style={{ display: 'flex', flexDirection: 'column', gap: '10px', fontFamily: 'Inter, sans-serif' }}>
    {[
      { name: 'extra-light', value: 200, cls: '.fw-extra-light' },
      { name: 'light', value: 300, cls: '.fw-light' },
      { name: 'regular', value: 400, cls: '.fw-normal (base)' },
      { name: 'medium', value: 500, cls: '.fw-medium' },
      { name: 'semibold', value: 600, cls: '.fw-semibold' },
      { name: 'bold', value: 700, cls: '.fw-bold' },
      { name: 'extra-bold', value: 800, cls: '.fw-extrabold' },
    ].map(({ name, value, cls }) => (
      <div key={value} style={{ display: 'flex', alignItems: 'baseline', gap: '16px', borderBottom: '1px solid rgba(0,0,0,.06)', paddingBottom: '8px' }}>
        <span style={{ fontWeight: value, fontSize: '20px', minWidth: '320px' }}>
          The quick brown fox
        </span>
        <span style={{ fontFamily: 'monospace', fontSize: '12px', color: '#667085' }}>
          {value} &nbsp;·&nbsp; {name} &nbsp;·&nbsp; {cls}
        </span>
      </div>
    ))}
  </div>
</Unstyled>
